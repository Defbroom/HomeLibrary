# Связанный каталог

Каждая сущность хранится в отдельном справочнике. В книге записаны постоянные идентификаторы, а отображаемые названия берутся из справочников.

| Файл | Содержимое | Ссылка из книги |
| --- | --- | --- |
| `books.js` | 1 404 книги: `id`, `title`, ссылки, `notes`, `rare` | — |
| `authors.js` | 705 написаний авторов: `id`, `name` | `authorId` |
| `cabinets.js` | 5 мест хранения: `id`, `name` | `cabinetId` |
| `shelves.js` | Общие полки 1–6 и «Антресоль»: `id`, `name` | `shelfId` |
| `rows.js` | Передний и задний ряды: `id`, `name` | `rowId` |
| `positions.js` | Слева, по центру, справа: `id`, `name` | `positionId` |
| `series.js` | 24 серии: `id`, `name` | `seriesId` |

Полка не принадлежит конкретному шкафу. Полка 2 в разных шкафах использует одну и ту же запись справочника; расположение задаётся сочетанием ссылок книги на шкаф, полку, ряд и положение.

## Правила изменений

- Идентификаторы уникальны внутри справочника, остаются постоянными и не пересчитываются при сортировке или переименовании.
- Для новой сущности выбирать ещё не использованный идентификатор. Для существующей использовать её прежний идентификатор.
- Пустой автор, полка, ряд, положение или серия задаются `null`. Шкаф обязателен.
- Похожие написания авторов не объединяются без проверки. Составные авторские строки из Excel сохранены как единые записи справочника.
- Примечания остаются текстом, раритет — логическим значением `true` или `false` в книге.
- Повторяющиеся исходные строки — отдельные книги с разными идентификаторами. При миграции ни одна строка не удалена.
- Перед удалением записи справочника проверить использующие её книги и обновить их ссылки.

## Загрузка страницы

`index.html` загружает справочники, книги, затем `resolve.js` и `app.js`. Сборка, серверная база данных и сетевые запросы для разрешения ссылок не нужны.

`resolve.js` проверяет уникальность идентификаторов и существование ссылок. Он создаёт `window.LIBRARY.catalog` с разрешёнными названиями для поиска и карточек. Это вычисляемое представление, его не нужно редактировать или сохранять как вторую базу. Исходные связанные записи находятся в `window.LIBRARY.books` и справочниках.
