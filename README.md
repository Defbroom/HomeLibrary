# Домашняя библиотека

Вики: какая книга где лежит. Откройте `index.html` в браузере.

Каталог хранится в `data/books.js`. В чате достаточно назвать:

1. название
2. автора
3. шкаф
4. полку
5. ряд — передний или задний
6. положение — слева, по центру или справа

Каталог заменён полным импортом из `книги.xlsx`: 1 404 записи. Сохранены все строки, включая повторы, примечания, серии и отметки раритета. Поиск также учитывает примечания и серии.

Названия и авторы при импорте сохранены как в исходной таблице. Пустые поля не дополнялись догадками: страница явно показывает, если автор или часть расположения не указаны. Числовые полки записаны как `полка N`, «Антресоль» сохранена как отдельное место хранения.
